## 🆕 Just shipped: [decisionkit](https://github.com/adityajha2005/decisionkit)

<a href="https://www.npmjs.com/package/@adxtya21/decisionkit"><img src="https://img.shields.io/npm/v/@adxtya21/decisionkit?style=flat-square&color=7F5AF0&label=npm" alt="npm version" /></a>
<img src="https://img.shields.io/badge/MCP-server-2CB67D?style=flat-square" alt="MCP server" />
<img src="https://img.shields.io/badge/Claude_Code-plugin-D97757?style=flat-square" alt="Claude Code plugin" />

> Fast, cheap decisions for coding agents, scripts and CI. Ask a yes/no, pick-one, score or rank question about some text and get **probabilities** back instead of paragraphs. It runs on the **OpenAI Decisions API**, **Jev** (TypeSafe AI) or **Claude**, and works as a CLI, an MCP server (for Codex, Cursor, VS Code and Zed) and a Claude Code plugin.
